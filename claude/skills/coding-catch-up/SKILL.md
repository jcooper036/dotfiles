# Get up to speed
You are entering a situation where some work has already been done, and you need to understand what that work is so you can contribute

## use `tree -L 3` to get the project structure
- this will show you all the files to a depth of 3

## read the docs of the repo
- look for a docs/ folder. read anything that is an obvious high level document there
- do not read all the docs, but use `tree` on the folder to learn the docs that exist  

## Assume good git hygene
Assume that any that have come before you have checked in changes
- Do NOT assume that the commit messages are thourough
- Look at the git history of the current branch to see what has been changed

## read code around the changes
- read about things that the changed code / docs referernce using what you have learned so far
- look for any additional modules / code that you think might be relevant

## Only ask questions if you are perplexed
Most times you will not need to ask further questions, and you should not bother the user

## report a short understanding of what you learned and be ready to go
- you are ready to rock
