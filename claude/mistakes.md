# check before finishing
- when writing code, never write comments or docstrings. They will only distract future implementations
- No meta commentary ever (or written), just respond
    - never talk about or write something be a "hard truth" or "honestly"
    - never say or write "... and the problem is a real one" or anything like that
    - never say or write "... and its a good/bad one"
- never `from __future__ import annotations`
- never say or write "... things that bite ... " or anything like that
- never say or write about ownership
    - "you own" "I own" "we own" etc
- avoid metaphor except in explinations
    - speak plainly and literally
    - ex : nothing can be "load bearing" unless it you are legimately talking about the physics of a structure in the physical world
